## 🎯 Project Overview

This repository documents my practice with **JavaScript Loops and Logic-Based Programming Challenges**.

The goal of this practice session was to strengthen my understanding of different loop structures and learn how to apply them to solve real programming problems.

I worked on 10 challenging exercises involving mathematical operations, number patterns, conditional logic, and interactive program simulations.

## 📚 Concepts Explored

| Concept | Description |
|---|---|
| `for` Loop | Repeating code using a loop counter |
| `while` Loop | Executing code while a condition is true |
| `do...while` Loop | Executing code at least once before checking a condition |
| Nested Loops | Using loops inside other loops |
| `break` | Terminating a loop |
| `continue` | Skipping the current iteration |
| `if-else` | Making decisions based on conditions |
| Modulus (`%`) | Checking remainders and divisibility |
| Number Manipulation | Reversing and analyzing numbers |
| Logical Operators | Combining multiple conditions |

## ⚙️ How to Run

**Prerequisite:** Node.js installed on your system.

**1. Clone the repository**

```bash

```

**2. Navigate to the project folder**

```bash
cd your-repository
```

**3. Run a practice file**

```bash
node q1.js
```

Replace `q1.js` with the exercise you want to execute.
